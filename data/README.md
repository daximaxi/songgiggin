# Lögin (data)

Hér á `library.json` að liggja: skráin sem GIGGARI sækir þegar appið opnast.

Til að uppfæra: Stillingar → Lög á GitHub → **Sækja library.json**, svo hér á GitHub: **Add file → Upload files**, slepptu skránni í þessa möppu og ýttu á **Commit changes**. Eldri skráin víkur fyrir nýju.

Appið sameinar: nýrri útgáfa hvers lags vinnur og ekkert nýrra á tækinu skrifast yfir.

Geymslan er opinber, svo allir sem finna hana geta lesið lögin.
